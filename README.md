# 냉장고 한눈에

냉장고에 남은 음식과 소비기한을 관리하고, 보유 재료를 기준으로 오늘의 메뉴를 추천하는 반응형 오프라인 PWA입니다.

## 주요 기능

- 음식명, 소비기한, 수량, 보관 장소 등록
- 음식명에 따른 냉장·냉동·실온 보관 장소와 추천 소비기한 제안
- 기본 추천값으로 빠르게 등록하고 필요할 때만 소비기한·보관 장소·수량 변경
- 음식별 메모 등록·수정
- 정확한 음식명 우선 매칭과 모호한 음식 종류 확인
- 음식 정보 수정·삭제, 사용 완료 후 되돌리기
- 모바일 상단 `＋` 버튼, 냉장고 현황 배너와 하단 시트를 이용한 빠른 등록
- 보관 중·곧 소비·여유 요약 필터와 검색·정렬
- JSON 백업 파일 내보내기·불러오기
- 앱 실행 시 소비기한 임박 음식 안내
- 식재료 대표 이미지 102종과 확장 유사어 자동 연결
- 오프라인 레시피 112종 추천
- 보유 재료 및 부족 재료 기반 추천
- PC와 모바일을 함께 지원하는 반응형 화면
- PWA 설치 및 오프라인 캐시
- 브라우저 로컬 저장소를 이용한 데이터 보관

## 데이터 보관

음식 정보는 서버로 전송하지 않고 현재 기기의 브라우저 저장소에만 보관합니다. 앱 삭제나 브라우저 데이터 초기화에 대비해 설정 화면에서 JSON 백업 파일을 내보내거나 복원할 수 있습니다. 새 사용자는 예시 음식 없이 빈 냉장고에서 시작합니다.

추천 소비기한은 일반적인 가정 보관 환경을 기준으로 한 참고값입니다. 제품 포장에 표시된 소비기한과 보관방법이 있으면 제품 표시를 우선합니다. 사용자가 같은 음식을 다시 등록하면 이전에 선택한 보관 장소와 기간을 우선 제안합니다.
추천 정보가 없는 음식에는 임의의 기본 기한을 적용하지 않으며, 사용자가 소비기한과 보관 장소를 직접 설정하도록 안내합니다.
`참치`처럼 여러 음식으로 해석될 수 있는 이름은 자동 추측하지 않고 참치캔·생참치·참치마요 등 구체적인 종류를 먼저 선택하게 합니다.

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
py -m http.server 8080
```

Chrome에서 `http://localhost:8080`을 엽니다.

PWA 설치 및 서비스 워커는 `file://` 직접 실행이 아니라 localhost 또는 HTTPS에서 활성화됩니다.

## 구성

- `index.html`: 화면 구조와 PWA 메타데이터
- `styles.css`: 데스크톱·모바일 반응형 스타일
- `app.js`: 음식 관리, 추천, 캐시 로직
- `recipes.js`: 오프라인 레시피 100종
- `service-worker.js`: 오프라인 서비스 워커
- `manifest.webmanifest`: PWA 설치 정보
- `assets/`: 식재료, 레시피, 앱 아이콘 이미지

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 정적 파일을 GitHub Pages에 배포합니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 합니다.

배포 주소는 `https://enjoyclover7.github.io/fridge-at-a-glance/`이며, PWA 경로와 매니페스트도 이 하위 경로를 기준으로 설정되어 있습니다.
