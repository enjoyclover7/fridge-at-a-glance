# 냉장고 한눈에

냉장고에 남은 음식과 소비기한을 관리하고, 보유 재료를 기준으로 오늘의 메뉴를 추천하는 반응형 오프라인 PWA입니다.

## 주요 기능

- 음식명과 소비기한 등록
- 전체·임박·여유 음식 필터
- 식재료 이미지 100종 자동 연결
- 오프라인 레시피 100종 추천
- 보유 재료 및 부족 재료 기반 추천
- PC와 모바일을 함께 지원하는 반응형 화면
- PWA 설치 및 오프라인 캐시
- 브라우저 로컬 저장소를 이용한 데이터 보관

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
py -m http.server 8080
```

Chrome에서 `http://localhost:8080`을 엽니다.

PWA 설치 및 서비스 워커는 `file://` 직접 실행이 아니라 localhost 또는 HTTPS에서 활성화됩니다.

## 구성

- `index.html`: 화면 구조와 PWA 메타데이터
- `styles.css`: 데스크톱·모바일 반응형 스타일
- `app.js`: 음식 관리, 추천, 캐시 로직
- `recipes.js`: 오프라인 레시피 100종
- `service-worker.js`: 오프라인 서비스 워커
- `manifest.webmanifest`: PWA 설치 정보
- `assets/`: 식재료, 레시피, 앱 아이콘 이미지
