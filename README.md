# 냉장고 한눈에

냉장고에 남은 음식과 소비기한을 관리하고, 보유 재료를 기준으로 오늘의 메뉴를 추천하는 반응형 오프라인 PWA입니다.

## 주요 기능

- 음식명과 소비기한 등록
- 모바일 상단 `＋` 버튼, 냉장고 현황 배너와 하단 시트를 이용한 빠른 등록
- 영수증 사진의 상품명·수량 인식 및 사용자 검토 후 일괄 등록
- 전체·임박·여유 음식 필터
- 식재료 이미지 100종 자동 연결
- 오프라인 레시피 100종 추천
- 보유 재료 및 부족 재료 기반 추천
- PC와 모바일을 함께 지원하는 반응형 화면
- PWA 설치 및 오프라인 캐시
- 브라우저 로컬 저장소를 이용한 데이터 보관

## 영수증 가져오기

영수증 사진은 서버로 업로드하지 않고 브라우저 안에서 Tesseract.js로 분석합니다. 인식 결과는 자동 저장되지 않으며, 사용자가 상품명·수량·소비기한을 확인한 항목만 냉장고에 추가됩니다.

- 지원 파일: 카메라 촬영 또는 앨범에서 선택한 15MB 이하 이미지
- 인식 언어: 한국어와 영어
- 첫 실행: OCR 엔진과 언어 데이터를 받기 위해 인터넷 연결 필요
- 이후 동작: 브라우저 캐시 상태에 따라 오프라인 재사용 가능
- 한계: 영수증에는 소비기한이 없으므로 사용자가 직접 입력해야 하며, 매장 인쇄 품질에 따라 상품명과 수량을 수정해야 할 수 있음

사진은 OCR 전에 자동 확대·흑백 변환·대비 보정을 거치며, 날짜·가격·특수문자를 정리하고 알려진 식품명으로 정규화합니다. 신뢰하기 어려운 후보는 선택을 해제한 상태로 `확인 필요`를 표시합니다.

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
py -m http.server 8080
```

Chrome에서 `http://localhost:8080`을 엽니다.

PWA 설치 및 서비스 워커는 `file://` 직접 실행이 아니라 localhost 또는 HTTPS에서 활성화됩니다.

## 구성

- `index.html`: 화면 구조와 PWA 메타데이터
- `styles.css`: 데스크톱·모바일 반응형 스타일
- `app.js`: 음식 관리, 추천, 캐시 로직
- `receipt.js`: 영수증 OCR, 상품 후보 정리, 검토·일괄 등록
- `recipes.js`: 오프라인 레시피 100종
- `service-worker.js`: 오프라인 서비스 워커
- `manifest.webmanifest`: PWA 설치 정보
- `assets/`: 식재료, 레시피, 앱 아이콘 이미지

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 정적 파일을 GitHub Pages에 배포합니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 합니다.

배포 주소는 `https://enjoyclover7.github.io/fridge-at-a-glance/`이며, PWA 경로와 매니페스트도 이 하위 경로를 기준으로 설정되어 있습니다.

> 영수증 OCR은 jsDelivr에서 버전이 고정된 Tesseract.js와 언어 데이터를 내려받습니다. 완전한 독립 오프라인 배포가 필요하면 해당 파일을 저장소에 직접 포함해야 합니다.
